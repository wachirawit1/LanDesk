# LanDesk 0.3.1 — รีโมทภายในองค์กรสำหรับ Windows (สไตล์ AnyDesk)

รุ่นนำร่องที่เชื่อมต่อด้วย IP บนเครือข่ายภายในองค์กร (LAN/VLAN) รองรับทั้งการให้เจ้าของเครื่องกดยอมรับและการเข้าด้วยรหัสผ่านที่เจ้าของเครื่องตั้งไว้ มาพร้อม **ตัวติดตั้งไฟล์เดียว (Setup Installer)**, **รันเซอร์วิสเบื้องหลังอัตโนมัติ (Tray)**, **คัดลอก-วางไฟล์ข้ามเครื่องผ่าน Clipboard**, **ตรวจหาอัปเดตอัตโนมัติจาก GitHub**, **สมุดรายชื่อเครื่อง (Address Book)**, **การสลับหลายหน้าจอ (Multi-Monitor)**, **ช่องแชทใน Session**, **การควบคุมสิทธิ์แบบ Real-time**, และ **การส่งไฟล์/โฟลเดอร์ (Auto-ZIP) พร้อมวางอัตโนมัติ**

## ติดตั้งและเปิดใช้งาน

- **แบบติดตั้งลงเครื่อง (แนะนำ):** ดับเบิลคลิก `LanDesk-Setup-v0.3.1.exe` เพื่อติดตั้งลงเครื่องในคลิกเดียว พร้อมสร้างไอคอน Desktop, Start Menu และรันเซอร์วิสเบื้องหลังทันที
- **แบบพกพา (Portable):** แตก `LanDesk-v0.3.1-Windows-x64.zip` ทั้งโฟลเดอร์ แล้วเปิด `LanDesk.exe` ไม่ต้องติดตั้ง Python
- สำหรับชุด source ให้ใช้ `Setup-LanDesk.cmd` แล้วเปิด `Start-LanDesk.cmd` แนะนำให้ใช้รุ่น 0.3.1 ทั้งสองเครื่อง (รองรับการคุยกับรุ่น 0.2.0 และ 0.3.0 ได้)

## เชื่อมต่อแบบให้ปลายทางกดรับ

1. ที่เครื่องปลายทาง กด **เปิดรับการเชื่อมต่อ** แล้วกด **คัดลอก IP** หรือบอก IP ให้เจ้าหน้าที่
2. ที่เครื่องเจ้าหน้าที่ กรอก IP หรือเลือกจาก **สมุดรายชื่อ (Address Book)** แล้วกด **เชื่อมต่อ**
3. การเชื่อมต่อครั้งแรก ให้เปรียบเทียบลายนิ้วมือกับหน้า **ตั้งค่าและความปลอดภัย → เครือข่ายและตัวตนเครื่อง** ของปลายทาง ผ่านเจ้าของเครื่องหรือฝ่าย IT แล้วจึงกดเชื่อถือ หลังจากนั้นโปรแกรมจะจำและตรวจให้อัตโนมัติ
4. ถ้าเครื่องปลายทางไม่มีรหัสผ่าน จะส่งคำขอให้กดรับทันที ถ้ามีรหัสผ่าน ให้เลือก **ส่งคำขอให้ปลายทางกดรับ**
5. เจ้าของเครื่องเลือกสิทธิ์เมาส์/คีย์บอร์ด, ข้อความ Clipboard และไฟล์ แล้วกดอนุญาตภายใน 30 วินาที ถ้าปฏิเสธหรือหมดเวลาจะไม่ส่งภาพ

## ตั้งรหัสผ่านเพื่อเข้าได้โดยไม่ต้องกดรับ & เปิดพร้อม Windows

ที่เครื่องปลายทาง เปิด **ตั้งค่าและความปลอดภัย → รหัสผ่านและสิทธิ์** ใส่รหัสใหม่สองช่อง ความยาว 12–128 ตัวอักษร เลือกสิทธิ์สำหรับผู้เข้าด้วยรหัสผ่าน และเลือกได้ว่าจะให้ **เปิดรับอัตโนมัติเมื่อเปิดโปรแกรม** รวมถึง **เปิดโปรแกรมพร้อม Windows เมื่อล็อกอินบัญชีผู้ใช้นี้ (Startup)** แล้วกดบันทึก

ในแท็บ **เครือข่ายและตัวตนเครื่อง** สามารถตั้ง **ชื่อเรียกเครื่องนี้ (Alias)** เช่น `แผนกบัญชี-01` เพื่อให้แสดงชื่อเครื่องบนหน้าต่างของผู้ที่รีโมทเข้ามา

## สมุดรายชื่อ (Address Book) และเช็กสถานะออนไลน์

- กรอก IP และชื่อเรียก แล้วกด **บันทึกชื่อ** เพื่อเก็บไว้ในสมุดรายชื่อ (เข้ารหัสด้วย Windows DPAPI)
- เมื่อเชื่อมต่อสำเร็จ โปรแกรมจะจำเครื่องและเวลาที่เชื่อมต่อล่าสุดลงในสมุดรายชื่อให้อัตโนมัติ
- กด **ติดดาว ★** เพื่อปักหมุดเครื่องที่ใช้บ่อยไว้ด้านบนสุด
- กด **เช็กสถานะออนไลน์** เพื่อตรวจสอบว่าเครื่องในรายการเปิดพอร์ตรับการเชื่อมต่ออยู่ใน LAN หรือไม่ (`ออนไลน์ (พร้อมรับ)` / `ออฟไลน์ / ปิดรับ`)
- ดับเบิลคลิกที่รายชื่อในตารางเพื่อเชื่อมต่อไปยังเครื่องนั้นได้ทันที

## ภาพ การสลับหลายหน้าจอ และการควบคุม

- **สลับหน้าจอ (Multi-Monitor):** หากเครื่องปลายทางมีหลายหน้าจอ แถบเครื่องมือด้านบนของ Viewer จะมีตัวเลือก **จอ 1**, **จอ 2, ...** และ **ทุกหน้าจอ** ให้สลับดูได้ทันที พร้อมคำนวณพิกัดเมาส์ตามหน้าจอที่เลือก
- **เมาส์ปลายทาง:** แสดงตำแหน่งเคอร์เซอร์ของเครื่องปลายทางซ้อนบนภาพ (เปิด/ปิดได้จากช่อง `เมาส์ปลายทาง`) และรองรับคลิกซ้าย คลิกกลาง (Middle Click) คลิกขวา และลูกกลิ้งเมาส์
- **โหมดภาพ:** `ภาพชัด` (JPEG 95 4:4:4 สูงสุด 4096×2160), `ไม่สูญเสียรายละเอียด` (PNG ไร้การบีบอัดสูญเสีย เหมาะกับตัวหนังสือ/ตาราง), และ `ลื่นไหล` (ย่อขนาดไม่เกิน 1600×1000)
- **ขนาด 100% / เต็มจอ:** แสดงขนาดพิกเซลจริงพร้อมเลื่อนด้วย scrollbar หรือกดปุ่ม **เต็มจอ (F11)**; กด `Ctrl+Alt+F12` เพื่อตัดการเชื่อมต่อทันที
- **ปรับสิทธิ์แบบ Real-time ขณะเชื่อมต่อ:** เจ้าของเครื่องปลายทางสามารถกดติ๊กเปิด/ปิดสิทธิ์ **เมาส์/คีย์บอร์ด**, **Clipboard ข้อความ**, และ **รับส่งไฟล์** ในกรอบ `เครื่องนี้ (This Desk)` ได้ตลอดเวลาขณะเชื่อมต่อโดยไม่ต้องตัดสาย

## แชทระหว่างรีโมท (In-Session Chat)

- ฝั่งผู้ช่วยกดปุ่ม **แชท (0)** มุมขวาบนของหน้าต่าง Viewer เพื่อเปิดแถบแชทด้านข้าง หากมีข้อความเข้าขณะพับแถบแชท ตัวเลขแจ้งเตือนจะเพิ่มขึ้นอัตโนมัติ
- ฝั่งเจ้าของเครื่องพิมพ์ตอบกลับได้ทันทีจากช่องแชทในหน้าหลักของโปรแกรม ข้อความส่งผ่านช่องทาง TLS เดียวกัน (สูงสุด 1,000 ตัวอักษรต่อข้อความ)

## Copy/Paste ข้อความ

ต้องอนุญาตสิทธิ์ Clipboard ก่อน คัดลอกข้อความในเครื่องผู้ช่วย จากนั้นโฟกัสภาพรีโมทแล้วกด `Ctrl+V` โปรแกรมจะส่งข้อความและสั่งวางที่ปลายทางเมื่อมีสิทธิ์ควบคุม หรือเลือกข้อความในภาพรีโมทแล้วกด `Ctrl+C` (หรือปุ่ม **รับสิ่งที่คัดลอก**) เพื่อนำข้อความมาวางในเครื่องผู้ช่วย

## ส่งไฟล์ / ส่งโฟลเดอร์ (Auto-ZIP) / Copy-Paste ไฟล์อัตโนมัติ

ต้องอนุญาตสิทธิ์ไฟล์ก่อน รองรับไฟล์ขนาดไม่เกิน 100 MB ต่อไฟล์ ครั้งละไม่เกิน 50 รายการ พร้อมแถบ Progress Bar แสดงความคืบหน้า

- **ส่งจากเครื่องผู้ช่วย (วางอัตโนมัติในครั้งเดียว):**
  - คัดลอกไฟล์หรือโฟลเดอร์ใน File Explorer ฝั่งผู้ช่วย แล้วโฟกัสภาพรีโมทและกด `Ctrl+V` โปรแกรมจะเริ่มโอนข้อมูลทันที และเมื่อโอนเสร็จจะสั่งวาง (`Ctrl+V`) ในหน้าต่างปลายทางให้อัตโนมัติโดยไม่ต้องกดซ้ำ
  - หรือใช้ปุ่ม **ส่งไฟล์…** / **ส่งโฟลเดอร์…** บนแถบเครื่องมือ
- **ส่งโฟลเดอร์ (Auto-ZIP):** เมื่อเลือกส่งโฟลเดอร์ โปรแกรมจะบีบอัดโฟลเดอร์เป็นไฟล์ `.zip` ชั่วคราวให้อัตโนมัติ (สูงสุด 100 MB / 2,000 ไฟล์ ข้าม symlink) แล้วส่งไปยังปลายทาง
- **รับจากปลายทาง:** เลือกไฟล์หรือโฟลเดอร์ใน File Explorer ของปลายทางผ่านภาพรีโมท แล้วกด `Ctrl+C` หรือกดปุ่ม **รับสิ่งที่คัดลอก** รอรับครบก่อนกลับมาวางที่เครื่องผู้ช่วยด้วย `Ctrl+V`
- **ยกเลิกโอนไฟล์โดยไม่ตัด Session:** กดปุ่ม **ยกเลิกโอนไฟล์** ได้ทั้งฝั่งผู้ช่วยและฝั่งปลายทาง โปรแกรมจะหยุดเฉพาะการโอนไฟล์และลบไฟล์ `.partial` ทันทีโดยที่การเชื่อมต่อรีโมทยังทำงานต่อได้ตามปกติ
- ไฟล์ที่รับจะเก็บใน `%LOCALAPPDATA%\LanDesk\Received` ใต้โฟลเดอร์สุ่มแยกแต่ละไฟล์ ตรวจ SHA-256 และติด Windows Mark of the Web ทุกไฟล์ กด **ไฟล์ที่รับ** เพื่อเปิดดู

## ระบบตรวจหาและอัปเดตเวอร์ชันจาก GitHub (สไตล์ FanControl)

LanDesk มาพร้อมระบบตรวจสอบเวอร์ชันใหม่ผ่าน GitHub Releases API:

- **ตรวจหาอัปเดตอัตโนมัติเมื่อเปิดโปรแกรม:** เมื่อเปิดโปรแกรม ระบบจะตรวจหา Release ล่าสุดจาก GitHub ในพื้นหลัง (ไม่บล็อกการเปิดโปรแกรม) หากพบเวอร์ชันใหม่กว่า จะแสดงหน้าต่างแจ้งเตือนแบบ FanControl พร้อมบันทึกการเปลี่ยนแปลง (Changelog)
- **อัปเดตและรีสตาร์ทอัตโนมัติในคลิกเดียว (1-Click Auto Update):** กดปุ่ม **⚡ อัปเดตและรีสตาร์ททันที** ในกล่องแจ้งเตือน โปรแกรมจะดาวน์โหลดไฟล์ `.zip` รุ่นล่าสุดพร้อม Progress Bar แตกไฟล์และสลับไฟล์โปรแกรมให้อัตโนมัติ แล้วเปิดเวอร์ชันใหม่ขึ้นมาทันที
- **ตรวจหาอัปเดตด้วยตนเอง:** กดปุ่ม **ตรวจหาอัปเดต** ที่แถบด้านบนของหน้าต่างหลัก หรือเข้าไปที่หน้า **ตั้งค่าและความปลอดภัย → แท็บ การอัปเดต (GitHub)** เพื่อระบุชื่อ Repository (เช่น `your-org/LanDesk` หรือ URL ของ GitHub) และกด **🔍 ตรวจหาอัปเดตเดี๋ยวนี้**
- **เปิดหน้า GitHub Release:** มีปุ่ม **🌐 เปิดหน้า GitHub** ให้เลือกเปิดดูรายละเอียดหรือดาวน์โหลดผ่าน Browser ได้เช่นกัน

## เครือข่าย ความเข้ากันได้กับ EDR และ Cybersecurity

- ใช้ TCP 45888 ตามปกติ (เปลี่ยนได้ในตั้งค่า) รองรับ IPv4 ภายในองค์กร (`10/8`, `172.16/12`, `192.168/16`, `127/8`) และกำหนด CIDR allowlist เพิ่มเติมได้
- TLS อย่างน้อย 1.2 พร้อม persistent certificate pinning, รหัสผ่านเก็บเป็น salted `scrypt`, และการตั้งค่า/สมุดรายชื่อเข้ารหัสด้วย Windows DPAPI (`%LOCALAPPDATA%\LanDesk\settings-v2.dat`)
- ปิดการใช้ UPX compression ในไฟล์ `.exe` และเก็บไฟล์ชั่วคราวขณะเตรียม SSLContext ไว้ในโฟลเดอร์ของแอปพร้อมระบบ retry เพื่อลดปัญหา Antivirus/EDR (เช่น SentinelOne) ล็อกไฟล์หรือแจ้งเตือน False Positive
- บันทึกเหตุการณ์ลง `audit.jsonl` (หมุนเวียนเมื่อเกิน 5 MB)

## ข้อจำกัด

ยังเป็นรุ่นนำร่อง (Pre-release) ที่ทำงานภายใต้ Session ของผู้ใช้ที่ล็อกอินอยู่ (ยังไม่ใช่ Windows Service ระดับ SYSTEM จึงยังไม่แสดงหน้า Windows Lock Screen หรือ UAC Prompt แบบ Secure Desktop), ไม่มีเสียง, ภาพเป็นเฟรม JPEG/PNG และโปรแกรมยังไม่ได้เซ็นใบรับรอง Code Signing
