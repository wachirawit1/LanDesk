# LanDesk 0.3.0 — ผลตรวจสอบ 5 พฤศจิกายน 2026

Windows 11 x64 / Python 3.12.14 / Pillow 12.3.0 / cryptography 50.0.1

ตรวจชุด Windows executable ที่ build สำหรับ LanDesk 0.3.0 (`upx=False`): เปิดหน้าต่าง LanDesk 0.3.0 ด้วยโปรไฟล์ทดสอบแยก และปิดผ่านหน้าต่างได้ตามปกติ (exit code 0)

ผ่าน automated tests ทั้งหมด 31 กรณี ครอบคลุม:

- เข้าด้วยรหัสถูกต้องโดยไม่เรียก consent, ไม่มีรหัสแล้วห้ามเข้าแบบ password, รหัสผิด, ปฏิเสธ/หมดเวลาคำขอ, การให้กดรับแม้ตั้งรหัสไว้
- TLS pin mismatch, IP allowlist พื้นฐาน, จำกัดการลองรหัสจาก IP เดียวและรวม, การหมดอายุช่วงจำกัด
- การไม่ส่งภาพก่อน consent, view-only, ถอนสิทธิ์ควบคุม, ปล่อยปุ่มเมาส์ (ซ้าย/กลาง/ขวา) และคีย์บอร์ดที่ค้าง, หยุดระหว่างรอ consent
- ข้อความ Clipboard ผ่าน TLS และการปฏิเสธ Clipboard/ไฟล์ที่ไม่ได้รับสิทธิ์ในฝั่ง server
- การโอนไฟล์ผ่าน TLS, โอนไฟล์สองทิศทาง, หลายก้อนข้อมูล, ชื่อซ้ำไม่ทับกัน, ไฟล์ว่าง, SHA-256 ผิด, ลำดับผิด, ขนาดเกิน, path traversal/ชื่ออุปกรณ์ Windows, cleanup ไฟล์ไม่สมบูรณ์
- **ใหม่ใน 0.3.0:** การส่งโฟลเดอร์แบบ Auto-ZIP ตรวจสอบโครงสร้างไฟล์ภายใน ZIP, การแจ้งเตือนเมื่อส่งครบชุดเพื่อวางอัตโนมัติ (Auto-Paste), และการยกเลิกการโอนไฟล์แบบไม่ตัด Session (`op: 'cancel'`) พร้อมลบไฟล์ `.partial` ทันที
- **ใหม่ใน 0.3.0:** โปรโตคอลรุ่น 3 รองรับการส่งชื่อเครื่อง (Alias), แชทสองทิศทางใน Session (`chat`), การเปิด/ปิดสิทธิ์แบบ Real-time ระหว่างเชื่อมต่อ (`set_permission`), และการสลับหลายหน้าจอ (`monitors`)
- **ใหม่ใน 0.3.0:** สมุดรายชื่อ (Address Book) บันทึก/จัดเรียงรายการโปรด/ลบรายชื่อ และเข้ารหัสด้วย Windows DPAPI ร่วมกับใบรับรองและรหัสผ่าน
- ภาพ lossless PNG ตรงทุกพิกเซลของภาพจำลอง และโหมด sharp ไม่ลดภาพ Full HD

ทดสอบการสร้างหน้าต่างหลัก หน้าตั้งค่า สมุดรายชื่อ กล่องยืนยันตัวตน กล่องเลือกรหัส/คำขอ กล่อง consent และ viewer (สลับ fit/100%, ตัวเลือกหลายหน้าจอ, แผงแชทและตัวนับข้อความใหม่) ผ่าน Tk จริงทั้งหมด
