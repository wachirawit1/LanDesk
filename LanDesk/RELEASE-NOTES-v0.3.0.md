# LanDesk v0.3.0 — AnyDesk-style Address Book, Live Permissions, Chat & Multi-Monitor (Pre-release)

## เปลี่ยนแปลงและฟีเจอร์ใหม่ในรุ่น 0.3.0

- **สมุดรายชื่อและเครื่องล่าสุด (Address Book & Recent Desks):** บันทึกชื่อเรียกเครื่อง/แผนก ติดดาวรายการโปรด เก็บเวลาเชื่อมต่อล่าสุด (เข้ารหัสด้วย Windows DPAPI) พร้อมปุ่ม **เช็กสถานะออนไลน์** ใน LAN และดับเบิลคลิกเพื่อเชื่อมต่อได้ทันที
- **ตั้งชื่อเครื่อง (Machine Alias) และปุ่มคัดลอก IP:** ตั้งชื่อเรียกเครื่องนี้ในหน้าตั้งค่า แสดงชื่อเครื่องให้ฝั่งที่เชื่อมต่อเห็น และคัดลอก IP ของเครื่องลง Clipboard ได้ในคลิกเดียว
- **ควบคุมสิทธิ์แบบ Real-time ระหว่างเชื่อมต่อ (Live Permission Shield):** เจ้าของเครื่องปลายทางสามารถเปิด/ปิดสิทธิ์ **เมาส์/คีย์บอร์ด**, **Clipboard ข้อความ**, และ **รับส่งไฟล์** ได้ตลอดเวลาขณะเชื่อมต่อโดยไม่ต้องตัดสาย
- **ช่องแชทใน Session (In-Session Chat):** ส่งข้อความสนทนาระหว่างผู้ช่วย (Viewer) และเจ้าของเครื่อง (Host) ผ่านช่องทาง TLS เดียวกัน พร้อมตัวนับข้อความใหม่
- **รองรับหลายหน้าจอ (Multi-Monitor Switcher) และแสดงเมาส์ปลายทาง:** เลือกสลับดู **จอ 1, จอ 2, ...** หรือ **ทุกหน้าจอ** ได้จากแถบเครื่องมือ พร้อมตัวเลือกวาดตำแหน่งเคอร์เซอร์ของเครื่องปลายทางลงบนภาพ และรองรับคลิกเมาส์ปุ่มกลาง (Middle Click)
- **ปรับปรุงการโอนไฟล์และ Copy-Paste แบบ AnyDesk:**
  - **ยกเลิกโอนไฟล์โดยไม่ตัด Session:** กดปุ่มยกเลิกโอนไฟล์จะหยุดเฉพาะไฟล์ที่กำลังรับ/ส่งและลบไฟล์ `.partial` ทันที โดยที่รีโมทไม่หลุด
  - **ส่งโฟลเดอร์ได้ทันที (Auto-ZIP):** เลือกส่งโฟลเดอร์หรือกด Ctrl+C / Ctrl+V โฟลเดอร์ โปรแกรมจะบีบอัดเป็น `.zip` ให้อัตโนมัติ (สูงสุด 100 MB / 2,000 ไฟล์)
  - **วางไฟล์อัตโนมัติ (Auto-Paste):** กด Ctrl+V ส่งไฟล์จากฝั่งผู้ช่วยเพียงครั้งเดียว เมื่อส่งครบจะสั่งวางที่ปลายทางให้อัตโนมัติ พร้อมแถบ Progress Bar แสดงเปอร์เซ็นต์
- **ระบบตรวจหาและอัปเดตเวอร์ชันจาก GitHub (สไตล์ FanControl):**
  - ตรวจหา Release ล่าสุดจาก GitHub อัตโนมัติเมื่อเปิดโปรแกรม หรือกดปุ่ม **ตรวจหาอัปเดต** ที่แถบเมนู
  - แสดงกล่องแจ้งเตือนเมื่อมีเวอร์ชันใหม่ พร้อมรายละเอียด What’s New
  - ปุ่ม **⚡ อัปเดตและรีสตาร์ททันที** สั่งดาวน์โหลดไฟล์ ZIP แสดง Progress Bar แตกไฟล์และสลับไฟล์โปรแกรมพร้อมรีสตาร์ทให้อัตโนมัติ
  - รองรับการตั้งค่า GitHub Repository (เช่น `owner/repo`) ในหน้าตั้งค่า
- **ความเข้ากันได้กับระบบความปลอดภัย (EDR / SentinelOne) และ DPI:**
  - ปิดการบีบอัด UPX ในชุด `.exe` และย้ายไฟล์ชั่วคราวตอนโหลดใบรับรอง TLS ออกจาก `%TEMP%` สาธารณะพร้อมระบบ retry เพื่อลดโอกาสเกิด False Positive หรือไฟล์ถูกล็อกจาก Antivirus/EDR
  - รองรับ Per-Monitor DPI Awareness V2 เพื่อให้พิกัดเมาส์แม่นยำบนจอที่ตั้ง Scale 125%–200%
  - เพิ่มตัวเลือกเปิดโปรแกรมอัตโนมัติเมื่อล็อกอิน Windows (Startup ระดับบัญชีผู้ใช้)
