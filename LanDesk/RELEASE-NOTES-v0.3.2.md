# 🚀 LanDesk v0.3.2 — Ultra-low Latency Mouse & Auto Clipboard Sync

LanDesk โปรแกรมรีโมทคอมพิวเตอร์ควบคุมหน้าจอความเร็วสูงผ่านระบบเครือข่ายภายใน (LAN / Wi-Fi / VPN) ทำงานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์ภายนอก ไม่ต้องต่อเน็ต มีความปลอดภัยสูงด้วยการเข้ารหัส TLS

---

### ✨ มีอะไรใหม่ในเวอร์ชัน 0.3.2 (What's New)

#### 🖱️ แก้ปัญหาเมาส์ดีเลย์และเงาเมาส์วิ่งตามหลัง (Zero-Latency Local Cursor)
- **ปิดเงาเมาส์ปลายทางเป็นค่าเริ่มต้น (Disable Remote Ghost Cursor):** ตัดภาพลวงตาเมาส์ดีเลย์ โดยใช้ Local Cursor จริงของเครื่องต้นทางที่ขยับได้ลื่นไหลทันที 0ms (60Hz / 144Hz) ตามมาตรฐาน AnyDesk / TeamViewer
- **ปลดล็อกคอขวด CPU ฝั่งปลายทาง:** ปรับระบบแปลงขนาดภาพเป็น Fast Nearest Scaling ลดเวลาประมวลผลจาก 22ms เหลือเพียง 1.8ms ต่อเฟรม ดันเฟรมเรตสูงขึ้น
- **ส่งและตอบสนองสัญญาณเมาส์ทันที (Immediate Input Dispatch):** สั่ง Windows `SetCursorPos` ทันทีใน 1ms เมื่อรับแพ็กเก็ต พร้อมเพิ่มรอบตรวจจับการขยับเมาส์เป็น 120 Hz
- **จัดลำดับคำสั่งคลิกเมาส์ไม่ให้คลาดเคลื่อน:** อัปเดตพิกัดเมาส์ให้ตรงกับตำแหน่งจริงก่อนส่งคำสั่งกดคลิก

#### 📋 ระบบตรวจจับ "คลิกขวา Copy" อัตโนมัติ & ขยายขนาดไฟล์
- **Auto-Detect Clipboard ฝั่งปลายทาง:** ไม่ว่าจะกด `Ctrl+C` หรือใช้เมาส์ **คลิกขวา ➔ Copy** บนหน้าจอปลายทาง ระบบจะตรวจจับและซิงค์ข้อมูล/ไฟล์กลับมาที่เครื่องต้นทางให้อัตโนมัติ
- **ขยายขีดจำกัดไฟล์และโฟลเดอร์:** รองรับการคัดลอกไฟล์ขนาดใหญ่สูงสุด **1 GB** (จากเดิม 100 MB) และรองรับได้ถึง **500 ไฟล์** (จากเดิม 50 ไฟล์)

#### 🎯 ปรับหน้าจอให้เรียบง่าย (Clean & Focused UI)
- ตัด Checkbox สิทธิ์และปุ่มที่ไม่ได้ใช้งานออกทั้งหมด เปิดโปรแกรมพร้อมรับการเชื่อมต่อทันที
- ตั้งรหัสผ่านได้อย่างอิสระตั้งแต่ 4 ตัวอักษรขึ้นไป
