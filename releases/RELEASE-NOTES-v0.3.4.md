# 🚀 LanDesk v0.3.4 — Reliable Typing, Direct Grave Accent (0x29) & Toolbar Shortcuts

LanDesk โปรแกรมรีโมทคอมพิวเตอร์ควบคุมหน้าจอความเร็วสูงผ่านระบบเครือข่ายภายใน (LAN / Wi-Fi / VPN) ทำงานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์ภายนอก ไม่ต้องต่อเน็ต มีความปลอดภัยสูงด้วยการเข้ารหัส TLS

---

### ✨ มีอะไรใหม่ในเวอร์ชัน 0.3.4 (What's New)

#### ⌨️ ปลดล็อกการพิมพ์ให้ทำงานลื่นไหล 100% ไม่ค้าง ไม่ดีเลย์ (Reliable Input Dispatch)
- **นำ Low-Level Hook ที่บล็อกการพิมพ์ออก:** แก้ไขปัญหาพิมพ์ข้อความไม่ติดในเวอร์ชัน 0.3.3 โดยกลับมาใช้ Direct Input Event Queue ที่ส่งปุ่มกด (ตัวอักษร, สัญลักษณ์, แป้นตัวเลข, Space, Backspace, Enter, ปุ่มลูกศร) ตรงไปยังเครื่องรีโมททันที 0ms
- **พิมภาษาไทยและอังกฤษได้ทันใจ:** ไม่หน่วง ไม่หลุด และไม่มีคำสั่งใดถูกบล็อก

#### 🌐 สลับภาษาด้วยปุ่ม `~` (Grave Accent Hardware Scan Code 0x29)
- **ส่งคีย์สแกนโค้ดฮาร์ดแวร์ตรงจุด:** เมื่อกดปุ่ม Grave Accent (`~`) โปรแกรมจะส่ง Virtual Key `0xC0` พร้อม Scan Code `0x29` ตรงไปยัง Windows เครื่องปลายทาง ทำให้ Windows ฝั่งปลายทางสลับภาษาได้ทันทีตามค่ามาตรฐานของ Windows ในไทย
- **รองรับ Shift + `~`:** หากกด Shift ร่วมกับ `~` จะพิมพ์สัญลักษณ์ `~` (Tilde) ตามปกติ
- **ปุ่ม "🌐 สลับภาษา (ไทย/EN)" บน Toolbar:** สามารถคลิกสลับภาษาผ่านแถบเครื่องมือด้านบนได้ทุกเมื่อ

#### 🪟 ปุ่ม Windows (Start Menu) และ Alt+Tab
- **ระงับ Start Menu เครื่องต้นทาง (Local Start Menu Suppression):** เมื่อกดปุ่ม Windows Key บนคีย์บอร์ด ระบบจะระงับไม่ให้ Start Menu บนเครื่องเราเด้งขึ้นมาแย่งโฟกัส และส่งคำสั่งไปเปิด Start Menu ที่เครื่องรีโมทแทน
- **เพิ่มปุ่มลัด 1-Click บน Toolbar:**
  - **`🪟 Win`**: กดเพื่อเปิด/ปิด Start Menu บนเครื่องรีโมททันที
  - **`🔄 Alt+Tab`**: กดเพื่อสลับหน้าต่างโปรแกรมบนเครื่องรีโมททันที
