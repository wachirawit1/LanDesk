# 🚀 LanDesk v0.3.5 — Fix Unsolicited File Transfer Disconnect & Smooth Sync

LanDesk โปรแกรมรีโมทคอมพิวเตอร์ควบคุมหน้าจอความเร็วสูงผ่านระบบเครือข่ายภายใน (LAN / Wi-Fi / VPN) ทำงานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์ภายนอก ไม่ต้องต่อเน็ต มีความปลอดภัยสูงด้วยการเข้ารหัส TLS

---

### ✨ มีอะไรใหม่ในเวอร์ชัน 0.3.5 (What's New)

#### 📂 แก้ปัญหาข้อผิดพลาด "ปฏิเสธการรับไฟล์ที่ไม่ได้ร้องขอ" แล้วหลุดการเชื่อมต่อ
- **สาเหตุที่เกิดขึ้นในเวอร์ชันก่อน:** เมื่อมีการ Copy ไฟล์บนเครื่องปลายทาง ระบบ Auto Clipboard Sync จะเริ่มส่งข้อมูลไฟล์มายังเครื่องต้นทางทันที แต่ตัวตรวจจับฝั่งต้นทางมีเงื่อนไข `accept_files` แบบเก่าค้างอยู่ ทำให้เกิด Exception `ValueError: ปฏิเสธการรับไฟล์ที่ไม่ได้ร้องขอ` และสั่งตัดการเชื่อมต่อทั้ง Session ไปทันที
- **การแก้ไขในเวอร์ชัน 0.3.5:**
  - นำเงื่อนไขขัดแย้ง `accept_files` ออกอย่างสมบูรณ์ เมื่อเชื่อมต่อและได้รับสิทธิ์รับส่งไฟล์ ระบบจะเปิดรับไฟล์ที่ซิงค์จาก Clipboard หรือการลาก/ส่งไฟล์ได้ทันที 100%
  - เพิ่มระบบ Safety Guard: หากมีการส่งไฟล์ในขณะที่ยังไม่ได้รับสิทธิ์รับส่งไฟล์ โปรแกรมจะยกเลิกเฉพาะการส่งไฟล์นั้นอย่างนุ่มนวล โดย **ไม่ตัดการเชื่อมต่อรีโมท** และหน้าจอจะยังคงควบคุมต่อเนื่องได้ตามปกติ
