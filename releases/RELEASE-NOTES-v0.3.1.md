# 🚀 LanDesk v0.3.1 — High Performance 30 FPS & Clean Remote Control

LanDesk โปรแกรมรีโมทคอมพิวเตอร์ควบคุมหน้าจอความเร็วสูงผ่านระบบเครือข่ายภายใน (LAN / Wi-Fi / VPN) ทำงานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์ภายนอก ไม่ต้องต่อเน็ต มีความปลอดภัยสูงด้วยการเข้ารหัส TLS

---

### ✨ มีอะไรใหม่ในเวอร์ชัน 0.3.1 (What's New)

#### ⚡ ปลดล็อกความเร็ว 30+ FPS ลดดีเลย์ภาพและเมาส์ (Performance & Ultra-low Latency)
- **Direct Win32 GDI Capture (`BitBlt`):** แคปเจอร์หน้าจอตรงจาก Framebuffer ลดเวลาจับภาพเหลือเพียง ~20ms
- **Turbo JPEG Compression (โหมด "ลื่นไหล" เป็นค่าเริ่มต้น):** บีบอัดภาพเร็วขึ้น 12 เท่า (~2.5ms) ขนาดไฟล์ต่อเฟรมเหลือเพียง 20–40 KB
- **ปลดล็อกขีดจำกัดเฟรมเรต 30+ FPS:** แสดงผลภาพต่อเนื่องและลื่นไหลติดตาในวง LAN
- **เปิด `TCP_NODELAY` (Zero Buffer Lag):** สัญญาณเมาส์และคีย์บอร์ดถูกส่งตรงทันที ไม่ถูกหน่วงเวลาด้วย Nagle's Algorithm
- **Fast Bilinear Canvas Blit & Mouse Coalescing:** เรนเดอร์ภาพบนหน้าจอทันที ไม่กระตุก และยุบคิวการขยับเมาส์ไม่ให้หน่วงสะสม

#### 🎯 ปรับหน้าจอให้เรียบง่าย (Clean & Focused UI)
- **ตัดปุ่มและ Checkbox สิทธิ์ที่รกออกทั้งหมด:** ไม่ต้องติ๊กเลือกสิทธิ์ยิบย่อย เจ้าของเครื่องกด **"อนุญาตให้เชื่อมต่อและควบคุม"** เพียงคลิกเดียว ได้สิทธิ์ควบคุมหน้าจอ เมาส์ คีย์บอร์ด และส่งไฟล์ครบถ้วนทันที
- **พร้อมรับการเชื่อมต่ออัตโนมัติ (Auto-Listen):** เปิดโปรแกรมขึ้นมาพร้อมรับการเชื่อมต่อทันที
- **ตั้งรหัสผ่านได้อย่างอิสระ:** รองรับรหัสผ่านตั้งแต่ **4 ตัวอักษรขึ้นไป**

#### 🔄 ตรวจหาและอัปเดตเวอร์ชันอัตโนมัติ (Built-in Auto Updater)
- ฝังคลังอัปเดตเข้ากับระบบโดยตรง ไม่ต้องก๊อปลิงก์มาวาง
- กด **"ตรวจหาอัปเดต"** แล้วกด **"⚡ อัปเดตเดี๋ยวนี้"** ระบบจะดาวน์โหลดและติดตั้งให้เสร็จสรรพในคลิกเดียว

#### 📦 ตัวติดตั้งและการทำงานแบบ AnyDesk / VNC
- **ตัวติดตั้งไฟล์เดียว (Single-file Setup):** ดับเบิลคลิก `LanDesk-Setup-v0.3.1.exe` ติดตั้งเสร็จในคลิกเดียว
- **ตัวถอนการติดตั้งครบวงจร:** มาพร้อม `Uninstall-LanDesk.exe` แสดง Path ตรงกับโฟลเดอร์ที่ติดตั้งจริง และลงทะเบียนใน Windows Settings ➔ Installed apps ถอนการติดตั้งได้สะอาดหมดจด
- **คัดลอกและวางไฟล์ข้ามเครื่อง:** คลิกขวา Copy ไฟล์ที่เครื่องต้นทาง แล้วคลิกขวา Paste หรือ Ctrl+V วางที่เครื่องปลายทางได้ทันที
