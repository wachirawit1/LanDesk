# LanDesk v0.3.1 — Setup Installer, Auto-Start Tray & File Clipboard Sync

## มีอะไรใหม่ในรุ่น 0.3.1 (What's New in v0.3.1)

- **ตัวติดตั้งและถอนการติดตั้งไฟล์เดียว (Setup Installer & Uninstaller):** ติดตั้งในคลิกเดียว พร้อมสร้างตัวถอนการติดตั้ง `Uninstall-LanDesk.exe` และลงทะเบียนใน Windows Settings -> Apps อัตโนมัติ
- **คัดลอกและวางไฟล์ข้ามเครื่อง (Seamless Clipboard Sync):** คลิกขวา Copy ไฟล์ที่เครื่องต้นทาง แล้วคลิกขวา Paste หรือ Ctrl+V วางที่เครื่องปลายทางได้ทันที
- **รันเซอร์วิสเบื้องหลังอัตโนมัติ (AnyDesk / VNC Style):** เริ่มทำงานใน System Tray ทันทีเมื่อเปิดเครื่อง และเปิดรับการเชื่อมต่อ (Auto-Listen) ให้อัตโนมัติโดยไม่ต้องกดปุ่มเปิดรับเอง
- **ระบบเช็คอัปเดตอัตโนมัติผ่าน GitHub Releases:** ตรวจหาเวอร์ชันใหม่จาก GitHub อัตโนมัติ พร้อมป๊อปอัปถามและปุ่ม `⚡ อัปเดตและรีสตาร์ททันที` ในคลิกเดียว
- **ไอคอนโปรแกรมใหม่:** ออกแบบไอคอนความละเอียดสูงฝังลงในโปรแกรม ตัวติดตั้ง ตัวถอนการติดตั้ง และแถบ System Tray
- **แก้ไขปุ่มโฟลเดอร์ไฟล์ที่รับ:** ปรับเลย์เอาต์แถบหัวโปรแกรมใหม่ ปุ่มไม่ถูกบีบอัด แสดงผลได้ชัดเจนทุกขนาดหน้าจอ
- **สมุดรายชื่อ (Address Book) และแชทในตัว:** บันทึก IP เครื่องที่เชื่อมต่อบ่อย และส่งข้อความสนทนาระหว่างรีโมทได้ทันที
