# 🚀 LanDesk v0.3.3 — Exclusive Fullscreen Keyboard Hook & Direct Language Switch

LanDesk โปรแกรมรีโมทคอมพิวเตอร์ควบคุมหน้าจอความเร็วสูงผ่านระบบเครือข่ายภายใน (LAN / Wi-Fi / VPN) ทำงานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์ภายนอก ไม่ต้องต่อเน็ต มีความปลอดภัยสูงด้วยการเข้ารหัส TLS

---

### ✨ มีอะไรใหม่ในเวอร์ชัน 0.3.3 (What's New)

#### ⌨️ โหมดจับคีย์ระดับลึก ส่งคำสั่งไปเครื่องรีโมท 100% (Exclusive Keyboard Focus & Fullscreen)
- **ดักจับคีย์ระดับลึกด้วย Win32 Low-Level Keyboard Hook (`WH_KEYBOARD_LL`):** เมื่อโฟกัสหน้าต่างรีโมทหรือเปิดเต็มจอ (F11) คีย์บอร์ดและปุ่มลัดทุกปุ่มจะถูกส่งตรงไปยังเครื่องปลายทางเพียงที่เดียว และถูกบล็อกไม่ให้ทำงานซ้ำซ้อนที่เครื่องต้นทาง
- **แก้ปัญหาปุ่มลัดทำงาน 2 ที่:** กดปุ่ม **Windows Key**, **Alt+Tab**, **Win+D**, **Win+E**, **Alt+F4**, **Ctrl+W** จะทำงานบนเครื่องรีโมทอย่างเดียว ไม่เด้ง Start Menu หรือสลับโปรแกรมบนเครื่องเรา
- **ปุ่มปลดฉุกเฉิน (Emergency Exit):** กด `Ctrl + Alt + F12` เพื่อปลดการจับคีย์และปิดหน้าต่างรีโมทได้ทันทีตลอดเวลา

#### 🌐 สลับภาษาไทย/อังกฤษได้สมบูรณ์ (Thai / English Language Switching)
- **กดปุ่ม `~` (Grave Accent) สลับภาษาที่เครื่องรีโมททันที:** ตัวดักจับคีย์จะส่งคำสั่งสลับภาษาไปยังเครื่องรีโมท และบล็อกไม่ให้เครื่องต้นทางเปลี่ยนภาษาตาม
- **เปลี่ยนภาษาตรงที่ Active Window ฝั่งปลายทาง:** สั่งเปลี่ยน Keyboard Layout ระหว่าง Thai Kedmanee (`0000041E`) และ English US (`00000409`) ผ่าน Win32 API ตรงจุด ทำให้พิมพ์ภาษาไทยในโปรแกรมต่างๆ ได้ทันที
- **ปุ่ม Toolbar สะดวก:** มีปุ่ม **"🌐 สลับภาษา (ไทย/EN)"** บนแถบเครื่องมือสำหรับคลิกสลับภาษาได้ด้วยเมาส์

#### 🔑 อนุญาตให้กรอกรหัสผ่านผิดได้ 3 ครั้ง (Password Retry Logic)
- กรอกรหัสผ่านผิดจะไม่ตัดการเชื่อมต่อทันที โดยจะแสดงข้อความเตือนสีแดงบอกจำนวนครั้งที่เหลือ (เช่น "รหัสผ่านไม่ถูกต้อง (เหลืออีก 2 ครั้ง)")
- สามารถลบและพิมพ์รหัสผ่านใหม่ได้ทันที

#### 🛠️ แก้ปัญหาตัวอัปเดตไฟล์ถูกล็อก & ข้อผิดพลาดพอร์ต 10048
- **ปลดล็อกไฟล์ก่อนอัปเดต (In-Use Process Overwrite):** ตัวติดตั้งและตัวอัปเดตอัตโนมัติจะปิดและปลดล็อกโพรเซส LanDesk ตัวเก่าอย่างสมบูรณ์ก่อนทำการคัดลอกทับ ทำให้หลังกดอัปเดตแล้วได้หน้าตาและฟีเจอร์เวอร์ชันใหม่ 100% ไม่ค้างที่เวอร์ชันเดิม
- **จัดการ Port Conflict นุ่มนวล:** ดักจับข้อผิดพลาด `[WinError 10048]` แสดงสถานะพอร์ตในหน้าจอหลักอย่างสุภาพ ไม่เด้งกล่องข้อผิดพลาดขึ้นมาขัดจังหวะ
